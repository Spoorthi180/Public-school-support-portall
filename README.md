# Public School Support Portal

## Overview

Public School Support Portal is a modern web application designed to streamline communication and academic resource management among students, teachers, parents, and administrators.

The platform provides role-based dashboards, assignment management, academic resource sharing, announcements, and performance tracking through a centralized system.

---

## Features

- Role-based access for Students, Teachers, Parents, and Administrators
- Assignment upload and management
- Academic resource sharing
- Student performance tracking
- Announcements and notifications
- Parent-Teacher communication
- Responsive dashboard interface
- Modern UI with reusable components
